# Flocking Simulation

My project is a Boids flocking simulation created in Python using Pygame.

The simulation demonstrates emergent group behavior using three main flocking rules:
Separation; Alignment; Cohesion

The project also includes obstacle avoidance, a movable obstacle controlled by arrow keys, edge wrapping and a smooth steering behavior

## The Controls
Arrow Keys -> Move the obstacle

## The Requirements

Installing pygame before running:
pip install pygame

## Running the Program
python RichardSalnikovflocking.py
